# Security and publication

Do not post API credentials, wallet recovery phrases, private keys, customer data or private application files in issues or pull requests. Use the private contact channel listed on the MoltAlpha website to report a security issue; do not include a live secret in the initial report.

Only public documentation and original integration examples belong in this repository. Its publication allowlist is enforced by a dependency-free check. That check is a safeguard, not a guarantee that arbitrary new content is safe to publish.

If a credential is exposed, remove it from current content and have its owner revoke or rotate it. Making a repository private or deleting a file does not invalidate an exposed credential or remove copies already made.
