## 3. Protection Plan & Non-Regression Guarantees

1. **Zero Production Changes During Development:**
   - All homepage work occurs on branch `feat/homepage-payment-repositioning` in `moltalpha-git`.
   - All SDK, example, documentation, and CLI tool work occurs on branch `feat/payment-sdk-and-toolkit-expansion` in `moltalpha-developers`.
   - Because Google Cloud Build deploys `www.moltalpha.dev` on merges to `main`, keeping changes on feature branches prevents any automatic production deployment until explicit owner approval.
2. **Preservation of Existing Routes & Components:**
   - Every existing `ActivePageView` route in `src/App.tsx` (`/`, `/sentinel`, `/forecasts`, `/automation`, `/member-chat`, `/developers`, `/pricing`, `/bounties`, `/nfts`, `/admin`) remains untouched in routing behaviour.
   - `TreasuryCheckoutPanel.tsx`, `DevelopersPricingPage.tsx`, and `multiChainSettlement.ts` preserve all SOL, USDC, Nano, BTC, ETH, and LTC settlement logic, Firestore `payment_claims` replay protection, and existing user credit balances.
3. **Strict Public Boundary Hygiene:**
   - Every new file added to `moltalpha-developers` is added deliberately to `scripts/check-public-boundary.mjs` and scanned to ensure zero private keys, tokens, internal IPs, or proprietary backend implementation details ever enter the public repository.
